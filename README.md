# 商品・ポイント計算 PWA

5つのExcel計算シートから、伝票・見積・インボイス印刷機能を除き、商品金額・ポイント・概算リース料の計算機能を統合したiPhone向けPWAです。

## GitHub Pagesの更新方法

1. `商品ポイント計算PWA_GitHubPages_ルート直下.zip` を解凍します。
2. GitHubの対象リポジトリを開き、`Add file` → `Upload files` を選びます。
3. 解凍後のファイルをすべてアップロードします。ZIPファイル自体はアップロードしません。
4. `Commit changes` を押します。
5. `Settings` → `Pages` で、公開元を `Deploy from a branch`、ブランチを `main`、フォルダを `/(root)` に設定します。

`index.html` がリポジトリの一番上に置かれていることを確認してください。日本語名フォルダの中へ入れた状態では、ルートURLにアプリが表示されません。

## 収録カテゴリ

- IG・FG
- 複合機 キット機
- 複合機 ハイパー機
- 複合機 ハイパー機（現金）
- 電話機 NYC-X

商品・オプション・トナー・サービス・工事保守を合わせて、元Excelから抽出した商品マスタを `catalog.json` に収録しています。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルを、リポジトリの最上位へすべてアップロードします。
3. リポジトリの「Settings」→「Pages」を開きます。
4. 「Deploy from a branch」を選び、`main` ブランチの `/ (root)` を指定して保存します。
5. 表示された公開URLをiPhoneのSafariで開きます。
6. Safariの共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように利用できます。

## 計算仕様

- 複合機・IG/FG：元Excelの基準価格、基準ポイント、刻み値を使い、売金差額からポイントを算出します。
- 本体ポイント：営業売金からオプション・保守・その他サービス売など本体以外の金額を引いて本体金額を求め、「基準ポイント −（定価 − 本体金額）÷ きざみ」を四捨五入します。その後、オプション・保守・下取りのポイントを加算します。
- 本体金額がマイナスになる場合も0円へ補正せず、その値を表示して本体ポイント計算へ使用します。
- オプション・保守の追加や数量変更では営業売金を自動加算しません。営業売金の初期値は本体商品の合計のみとし、本体以外の金額が大きい場合は本体金額が0円以下になります。
- 計算結果には「正味決済額」ではなく、入力またはリース料から逆算した「営業売金」を表示します。
- 電話機：商品一覧のリース用・現金用ポイントを契約区分に応じて使用します。
- オプション等：元Excelの価格・ポイントを数量に応じて合算します。
- 保守契約：専用の選択欄から追加できます。ハイパー機（リース95件・現金89件）、キット機3件、電話機4件の元Excel保守マスタを収録し、金額とポイントを合算します。
- その他サービス売上：売金から控除し、複合機・IG/FGのポイント対象売金および正味決済額に反映します。
- 下取り区分：なしはポイント影響なし、自社機ありは最終合計へ5ポイント加算、他社機ありは最終合計へ10ポイント加算してから1.2倍し、整数へ四捨五入します。下取金額の入力・控除は行いません。
- リース料：入力された正味決済額と料率から月額概算を100円未満切り捨てで算出します。
- 「リース料から逆算」を選ぶと、希望月額から代弁合計を差し引いた実質リース料を料率で割り、100円未満を切り捨てて売金を逆算します。ポイントも逆算された売金から再計算します。
- 逆算した売金は税別表示です。標準料率は、3年3.45%（代弁3.2%）、4年2.75%（代弁2.5%）、5年2.28%（代弁2.0%）、6年1.96%（代弁1.8%）、7年1.79%（代弁1.6%）です。
- 営業売金：入力した売金から「その他サービス売」を控除した金額を、上部と計算結果に表示します。
- 代弁：①レベルアップは「旧リース月額 × 残回数 × 1.1 × 代弁料率」、②単純解約は「旧リース月額 × 残回数 × 代弁料率」で算出し、新契約の月額リース料へ加算します。
- 入力内容は端末内に自動保存されます。外部送信は行いません。

## 更新方法

商品マスタを更新する場合は `catalog.json` を差し替え、`service-worker.js` の `CACHE` 名を新しい値へ変更してください。これにより利用端末のキャッシュが更新されます。
