# 商品・ポイント計算 PWA

5つのExcel計算シートから、伝票・見積・インボイス印刷機能を除き、商品金額・ポイント・概算リース料の計算機能を統合したiPhone向けPWAです。

## 収録カテゴリ

- IG・FG
- 複合機 キット機
- 複合機 ハイパー機
- 複合機 ハイパー機（現金）
- 電話機 NYC-X

商品・オプション・トナー・サービス・工事保守を合わせて、元Excelから抽出した商品マスタを `catalog.json` に収録しています。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルを、リポジトリの最上位へすべてアップロードします。
3. リポジトリの「Settings」→「Pages」を開きます。
4. 「Deploy from a branch」を選び、`main` ブランチの `/ (root)` を指定して保存します。
5. 表示された公開URLをiPhoneのSafariで開きます。
6. Safariの共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように利用できます。

## 計算仕様

- 複合機・IG/FG：元Excelの基準価格、基準ポイント、刻み値を使い、売金差額からポイントを算出します。
- 電話機：商品一覧のリース用・現金用ポイントを契約区分に応じて使用します。
- オプション等：元Excelの価格・ポイントを数量に応じて合算します。
- リース料：入力された正味決済額と料率から月額概算を100円未満切り捨てで算出します。
- 「リース料から逆算」を選ぶと、希望月額から代弁合計を差し引いた実質リース料を料率で割り、100円未満を切り捨てて売金を逆算します。ポイントも逆算された売金から再計算します。
- 代弁：旧リース①・②の月額、残回数、当時の税率、代弁料率から代弁額を算出し、新契約の月額リース料へ加算します。通常時は税込解約金、単純解約・インボイス対象外時は税別解約金を料率計算の対象にします。
- 入力内容は端末内に自動保存されます。外部送信は行いません。

## 更新方法

商品マスタを更新する場合は `catalog.json` を差し替え、`service-worker.js` の `CACHE` 名を新しい値へ変更してください。これにより利用端末のキャッシュが更新されます。
